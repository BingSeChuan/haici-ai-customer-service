# 云杉ERP 常见问题 FAQ

> 本文档汇总云杉ERP 用户最常咨询的问题。涉及退款、账号、发票等事项的，均以本文档描述为准。

## 一、账号与登录

**Q1：忘记密码怎么办？**
答：在登录页面点击"忘记密码"，输入注册手机号，系统发送短信验证码，验证通过后即可重置密码。

**Q2：员工账号如何添加？**
答：管理员在"系统设置 → 账号管理"中添加账号，输入员工手机号和姓名。标准版最多5个账号，专业版最多20个账号，旗舰版不限数量。

## 二、订单与发货

**Q3：订单录错了怎么修改？**
答：未审核的订单可直接修改；已审核的需先"反审核"再编辑；已出库的订单不允许反审核，必须通过"退货单"处理。

## 三、财务与发票

**Q4：如何开具发票？**
答：在"财务 → 发票管理"中创建开票申请。电子发票一般1个工作日内开具；纸质发票审核通过后3-5个工作日内寄出；发票已开具的需走"红字发票"流程作废重开。

**Q5：订阅到期后数据会丢失吗？**
答：不会。到期后有30天宽限期，宽限期内数据只读、可正常导出；超过30天未续费账号被冻结，冻结180天后数据被删除且无法恢复。

## 四、退款与售后

**Q6：软件不想要了能退款吗？**
答：订阅购买后7天内未使用（无登录记录）可申请全额退款；已使用超过7天的一般不予退款，但可申请将剩余订阅期折算为优惠券。具体规则以《退换货政策》为准。

**Q7：退款到账需要多久？**
答：退款审核通过后原路退回。支付宝/微信支付一般1-3个工作日到账，银行转账一般3-7个工作日到账。

## 五、系统与安全

**Q8：数据安全如何保障？**
答：标准版数据存储于云服务器，启用加密传输和每日自动备份；专业版及以上支持"异地容灾"。未经企业授权，云杉科技不会向任何第三方提供客户数据。

**Q9：可以私有化部署吗？**
答：可以。旗舰版支持私有化部署，数据完全存储在企业内网，需提供至少8核16G内存的服务器，部署周期一般为5-10个工作日。

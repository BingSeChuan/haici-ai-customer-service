# 云杉ERP 常见问题 FAQ

> 本文档汇总了云杉ERP 用户最常咨询的问题。涉及退款、账号、发票等事项的，均以本文档描述为准。

## 一、账号与登录

**Q1：忘记密码怎么办？**
答：在登录页面点击"忘记密码"，输入注册手机号，系统会发送短信验证码，验证通过后即可重置密码。重置后请使用新密码登录。

**Q2：员工账号如何添加？**
答：管理员在"系统设置 → 账号管理"中点击"添加账号"，输入员工手机号和姓名即可。注意：不同版本对账号数量有限制，标准版最多5个账号，专业版最多20个账号，旗舰版不限数量。超出账号数量上限时，需先升级版本或停用旧账号。

**Q3：账号被锁定怎么办？**
答：连续输错密码5次，账号将被临时锁定30分钟。锁定期间无法登录，30分钟后自动解锁。如急需使用，可联系管理员在后台手动解锁。

## 二、订单与发货

**Q4：订单录错了怎么修改？**
答：未审核的订单可直接修改；已审核的订单需要先"反审核"，再编辑。注意：已出库的订单不允许反审核，必须通过"退货单"处理。

**Q5：发货后如何通知客户？**
答：在订单详情中勾选"发送发货通知"，系统将自动向客户预留的手机号发送短信通知（仅限专业版及以上版本）。

**Q6：支持批量导入订单吗？**
答：支持。在"订单管理"页面点击"批量导入"，下载模板填写后上传即可。单次最多导入1000条订单，导入后请务必核对导入结果报告。

## 三、财务与发票

**Q7：如何开具发票？**
答：在"财务 → 发票管理"中创建开票申请，填写抬头和金额后提交。电子发票一般1个工作日内开具；纸质发票在审核通过后3-5个工作日内寄出。

**Q8：发票抬头写错了能改吗？**
答：发票未开具前可作废重开；发票已开具的，需走"红字发票"流程作废重开，请提前联系在线客服协助处理。

**Q9：订阅到期后数据会丢失吗？**
答：不会。订阅到期后有30天宽限期，宽限期内数据只读、可正常导出；超过30天未续费，账号将被冻结，冻结180天后数据将被删除且无法恢复。请务必在宽限期内续费或导出数据。

## 四、退款与售后

**Q10：软件不想要了能退款吗？**
答：订阅购买后7天内未使用（无登录记录）可申请全额退款；已使用超过7天的一般不予退款，但可以申请将剩余订阅期折算为优惠券。具体规则以《退换货政策》为准。

**Q11：退款到账需要多久？**
答：退款申请审核通过后，原路退回至支付账户。支付宝/微信支付一般1-3个工作日到账，银行转账一般3-7个工作日到账。

## 五、系统与安全

**Q12：云杉ERP 支持哪些浏览器？**
答：推荐使用 Chrome、Edge、Firefox 的最新版本，也支持 Safari。请勿使用 IE 浏览器访问，否则部分功能可能无法正常使用。

**Q13：数据安全如何保障？**
答：标准版数据存储于云服务器，启用加密传输和每日自动备份；专业版及以上支持"异地容灾"，数据安全性等级更高。所有版本均承诺：未经企业授权，云杉科技不会向任何第三方提供客户数据。

**Q14：可以私有化部署吗？**
答：可以。旗舰版支持私有化部署，数据完全存储在企业内网，需提供至少8核16G内存的服务器，部署周期一般为5-10个工作日。
